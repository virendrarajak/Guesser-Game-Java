# Guesser Game 🎯

A simple Guesser Game developed using Core Java.

## Technologies Used

* Core Java
* Scanner
* Classes and Objects
* Methods
* If-Else Conditions

## How It Works

1. Guesser enters a number.
2. Three players enter their numbers.
3. Umpire compares the numbers.
4. The game displays the winner.
5. The game ends.
